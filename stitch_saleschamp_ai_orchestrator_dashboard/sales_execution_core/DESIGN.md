## Brand & Style

The design system projects precision, velocity, and enterprise-grade institutional trust. It merges the focused, keyboard-friendly momentum of developer-grade tooling with the systematic data density demanded by global enterprise revenue operations. The interface must feel immediate, sharp, and confident—eliminating administrative drag while visualizing high-stakes pipeline intelligence.

The aesthetic philosophy balances modern corporate structure with crisp modern product styling:
- **Structural Clarity:** Pure optical alignment, razor-sharp 1px dividers, and an intentional avoidance of visual clutter.
- **Data Denseness with High Legibility:** Information-dense tables, deal pipelines, and metric trackers engineered to be parsed in milliseconds.
- **Deterministic Semantics:** Intentional color coding delineates system automation, manual interventions, deal velocity, and execution health.

## Colors

The palette establishes clear visual hierarchy across ambient canvases, elevated cards, and functional interaction targets.

### Canvas & Surfaces
- **App Background / Canvas:** `#F8FAFC` (Slate 50) provides an anti-glare, calm foundation that separates window boundaries from application content.
- **Card & Modal Surfaces:** Pure `#FFFFFF` elevates active working areas from the canvas.
- **Muted / Inset Surfaces:** `#F1F5F9` (Slate 100) handles table headers, nested card containers, and disabled control states.

### Borders & Structural Lines
- **Primary Hairline Borders:** `#E2E8F0` (Slate 200) applied consistently at 1px thickness for card boundaries, table cell grids, and section dividers.
- **Interactive / Input Borders:** `#CBD5E1` (Slate 300) for unselected inputs and neutral button perimeters, transitioning to `#4F46E5` on focus.

### Core Brand & Interaction
- **Primary (Electric Indigo):** `#4F46E5` drives primary actions, selected navigation states, interactive toggle fills, and primary key metrics.
- **Secondary (Enterprise Cyan):** `#0EA5E9` provides visual telemetry for secondary indicators, live sync streams, and real-time connectivity states.
- **Tertiary (Autonomous Purple):** `#8B5CF6` reserved strictly for machine intelligence, automated outreach, scoring models, and AI agent execution.

### Enterprise Semantics
- **Success / Synced:** `#10B981` (Emerald 500) paired with `#ECFDF5` background for ERP sync, successful billing cycles, and closed-won states.
- **Warning / Review Required:** `#F59E0B` (Amber 500) paired with `#FFFBEB` background for Human-in-the-Loop interventions, stalled sequences, and compliance verification.
- **Critical / Blocker:** `#EF4444` (Rose 500) paired with `#FEF2F2` background for deal slippage, churn signals, API failures, and contract escalations.
- **Text Hierarchy:** Primary headings and numeric labels use `#0F172A` (Slate 900); secondary descriptions and column headers use `#64748B` (Slate 500); disabled labels use `#94A3B8` (Slate 400).

## Typography

The typographic hierarchy separates structural brand framing, dense transactional reading, and quantitative data parsing.

- **Plus Jakarta Sans** provides structural character across headers, KPIs, and modal titles. Its geometric foundation lends an executive presence without sacrificing warmth.
- **Inter** controls body content, interactive labels, table rows, and form inputs. Configured with standard tracking to maintain legibility in dense tables.
- **JetBrains Mono** is reserved for quantitative tabular data, contract values, transaction IDs, status codes, and timestamps.
- **Tabular Figures:** All numeric rendering across both Inter and JetBrains Mono must enforce `font-feature-settings: "tnum" 1, "cv05" 1` to guarantee alignment across data columns.

## Layout & Spacing

The layout model implements a structured multi-pane application layout using a base 8px grid with a 4px half-step for micro-adjustments in dense data displays.

### Layout Topology
- **Desktop (1280px+):** Tri-panel architecture composed of:
  - Collapsed utility rail (`nav-rail-width`: 72px) or expanded primary navigation (`sidebar-width`: 256px).
  - Primary working canvas with a fluid grid, 24px exterior margin, and 16px horizontal/vertical card gutters.
  - Contextual sliding drawer or inspector panel (fixed 380px or 440px width) docking to the right boundary.
- **Tablet (768px - 1279px):** Primary navigation collapses to the 72px utility rail. Secondary inspector collapses to a modal overlay or off-canvas sheet. Margin reduces to 16px.
- **Mobile (< 768px):** Single-column layout. Navigation shifts to a persistent bottom bar (64px) or drawer. Table structures reflow into stacked key-value cards.

### Grid Rhythm & Spacing Rules
- Metric blocks and data cards utilize a strict internal padding of `space-xl` (24px) for high-level summaries and `space-base` (16px) for high-density tables and list widgets.
- Row heights across tables enforce three density tiers: Compact (32px), Standard (44px), and Expanded (56px).

## Elevation & Depth

Visual hierarchy is maintained primarily through surface contrast and crisp 1px borders, supported by layered, low-opacity ambient shadows.

### Elevation Levels

- **Base (Level 0 - Inactive/Canvas):** `#F8FAFC`. Flat, zero shadow. Used for the base frame and non-interactive sections.
- **Resting Surface (Level 1 - Cards, Toolbars):** `#FFFFFF` surface enclosed by a 1px solid border in `#E2E8F0`. Shadow: `0px 1px 2px rgba(15, 23, 42, 0.04), 0px 1px 3px rgba(15, 23, 42, 0.02)`.
- **Raised Interactive (Level 2 - Hovered Cards, Active Segments):** `#FFFFFF` surface enclosed by `#CBD5E1`. Shadow: `0px 4px 6px -1px rgba(15, 23, 42, 0.05), 0px 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Floating Overlays (Level 3 - Dropdowns, Popovers, Filter Menus):** `#FFFFFF` surface enclosed by `#CBD5E1`. Shadow: `0px 10px 15px -3px rgba(15, 23, 42, 0.08), 0px 4px 6px -4px rgba(15, 23, 42, 0.03)`.
- **Modal & Critical Sheets (Level 4 - Command Palette, Confirmation Modals):** `#FFFFFF` surface with a subtle 1px border. Shadow: `0px 20px 25px -5px rgba(15, 23, 42, 0.1), 0px 8px 10px -6px rgba(15, 23, 42, 0.05)`. Backdrops use `#0F172A` with 30% opacity and a 4px blur (`backdrop-filter: blur(4px)`).

No colored or saturated glow shadows are permitted for resting surfaces; glowing boundary rings (`box-shadow: 0 0 0 3px rgba(79, 70, 229, 0.15)`) are restricted entirely to keyboard focus states.

## Shapes

The design system pairs refined curvature with structural geometry. Containers adopt rounded perimeters to soften analytical data surfaces, while internal controls maintain balanced, tighter radii.

- **Cards and Panels:** Standardize on `rounded-xl` (0.75rem / 12px) to frame metrics, pipeline charts, and grouped data grids cleanly.
- **Buttons, Inputs, and Selectors:** Standardize on 6px (`rounded-md` / 0.375rem) to ensure a precise, crisp edge on interactive fields.
- **Badges, Status Indicators, and Pill Counters:** Use full circular rounding (`rounded-full` / 9999px) to distinguish metadata from actionable square-cornered inputs.
- **Modals and Flyout Sheets:** Use 16px (`rounded-2xl` / 1rem) on detached dialogue modals; attached slide-out drawers use 0px radius along docked edges.

## Components

### Buttons
- **Primary:** Background `#4F46E5`, text `#FFFFFF`, 6px radius, font Inter Medium 13px/14px. Hover: `#4338CA`. Active: `#3730A3`. Focus-visible: 2px ring `#4F46E5` with a 2px white offset.
- **Secondary:** Background `#FFFFFF`, 1px solid `#E2E8F0`, text `#0F172A`. Hover: `#F8FAFC` and border `#CBD5E1`.
- **Subtle / Ghost:** Transparent background, text `#64748B`. Hover: `#F1F5F9`, text `#0F172A`.
- **AI Action Button:** Gradient border or accent background tint `#F5F3FF`, text `#6D28D9`, 1px border `#DDD6FE`, with trailing tertiary star icon.

### Status Badges & Pills
- Badges use pill geometry (`rounded-full`), `space-xs` (2px) top/bottom, `space-sm` (8px) left/right, font `label-xs` (11px semi-bold).
- **SAP / Sync Success:** Background `#ECFDF5`, text `#065F46`, 1px border `#A7F3D0`. Includes a static 6px filled emerald dot indicator.
- **Human Review Required (Amber):** Background `#FFFBEB`, text `#92400E`, 1px border `#FDE68A`.
- **Blocker / SLA Breach (Rose):** Background `#FEF2F2`, text `#991B1B`, 1px border `#FECACA`.
- **Autonomous AI Action (Purple):** Background `#F5F3FF`, text `#5B21B6`, 1px border `#DDD6FE`.

### Data Cards
- Background `#FFFFFF`, 1px solid border `#E2E8F0`, 12px corner radius (`rounded-xl`).
- Padding: 20px on desktop, 16px on mobile.
- Headers separate card title (font `headline-sm`, `#0F172A`) from action controls using an optional muted bottom divider.

### Form Inputs & Selectors
- Height: 36px default, 32px compact.
- Background: `#FFFFFF`, 1px solid `#CBD5E1`, 6px corner radius.
- Text: 14px Inter, placeholder `#94A3B8`. Focus: border `#4F46E5`, box-shadow `0 0 0 3px rgba(79, 70, 229, 0.12)`.
- Input fields with monospaced values (IDs, deal quantities, currency amounts) apply `JetBrains Mono` at 13px.

### Checkboxes & Radio Buttons
- Checkbox: 16px x 16px square, 4px border radius. Unchecked: 1.5px solid `#CBD5E1`, background `#FFFFFF`. Checked: background `#4F46E5`, border `#4F46E5`, check glyph in `#FFFFFF`.
- Radio: 16px circular boundary. Selected: solid `#4F46E5` outer ring with a 6px white center dot.

### Tables & Deal Lists
- Header Row: Height 36px, background `#F8FAFC`, border-bottom 1px solid `#E2E8F0`. Text: `label-xs` (11px), uppercase, tracking `0.05em`, color `#64748B`.
- Content Row: Height 44px standard, background `#FFFFFF`, border-bottom 1px solid `#F1F5F9`. Hover: background `#F8FAFC`.
- Selected Row: Background `#EEF2FF`, left border accent 3px solid `#4F46E5`.

### Enterprise Command Palette (K-Bar)
- Modal floating centered at top 15% viewport. Max width 640px, rounded-2xl, background `#FFFFFF`, shadow Level 4.
- Integrated search bar with 48px height, no border, text 16px, leading search icon, trailing keyboard shortcut badges (`⌘K`, `ESC`).
